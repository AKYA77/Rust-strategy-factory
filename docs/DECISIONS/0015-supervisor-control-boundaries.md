# Coordinator control boundary and remaining supervisor work

Implemented prerequisite: search and fleet controls revoke the coordinator token/expiry when pausing, stopping or transitioning back to running. A quick pause followed by resume cannot resurrect a previous token. Reasserting running on an already-running coordinator retains its current lease. Replacement attempts still increase through the shared claim path; an old actor's release cannot clear the replacement. Child experiment tokens/checkpoints/results remain separate, so already committed child receipts can be reconciled after coordinator revocation. This does not cancel independent child processes or prevent their valid receipt commits.

The existing coordinator tests now exercise pause, immediate resume, rejected old publication/fence, replacement claim, stale release and a repeated running control that preserves the replacement lease. Existing corpus tests/browser flows continue to cover child-lease preservation, cached-result recovery, explicit error requeue, irreversible stop and safe-boundary restart. No automatic retry or process supervisor is claimed by this change.

## Next implementation boundary (proposed, not implemented)

Current generated-search worker errors and operator controls both store `state='paused'`. Their cause cannot be inferred safely from the presence of error slots: an operator may deliberately pause a failed search. Before enabling automatic retry, persist explicit operator/worker-error/legacy-unknown pause origin and the associated control epoch/timestamp atomically with state. Treat old ambiguous pauses as requiring explicit operator action. A resumed/replaced coordinator must remain fenced by both its token/attempt and the control epoch; never revive a token from a previous pause.

Freeze an opt-in bounded operational supervision policy before automatic actions. Preserve financial keys and existing immutable queue bodies. Reuse the existing per-slot maximum of three requeues, frozen queue-capacity checks and prior-error journal. Add typed retry eligibility rather than parsing human error strings; malformed inputs, corrupted evidence, financial/configuration refusals and permanent terminal outcomes must not become implicitly recoverable. Add durable backoff deadlines and bounded session action counts. Clock rollback, missing observations, exhausted history/capacity, held child leases and permanent terminal child results must produce explicit held/refused outcomes without busy spinning or clearing evidence. A retry is not a new candidate, financial trial, qualification or proof that a simulation ran.

Record actual supervisor starts/exits/retry decisions under bounded durable history with verified backups. Logging quotas must not make permanent stop impossible. Distinguish an application worker-error retry from process restart and from an OS-killed worker. A worker process cannot claim completion merely because the parent exited. Preserve separate coordinator and child experiment fences and actual committed receipt reuse at every crash boundary. Signal/timeout handling must operate on actually owned child processes and reap them; do not promise a persistent daemon after a foreground command ends.

Integrate explicit status/CLI and authenticated CSRF-protected controls/exact exports without accepting metrics or arbitrary executable paths from a browser. Test operator pause racing with an automatic retry, simultaneous supervisors, expired/replaced leases, durable backoff across restart, backwards clock, full retry/history budget, child-commit-before-parent-update, actual SIGKILL/SIGTERM/restart and disk-pressure refusal. Hard OS resource enforcement, stalled filesystem deadlines, production systemd/VPS and real-data/scientific qualification remain separate acceptance requirements.

Concrete starting points: `corpus_search::control`, `corpus_search::step`'s errored publication transaction, `requeue_errors`, shared `coordinator` claim/fence/release, `operator_config::SearchFile`, the corpus-search CLI loop, and the existing search process/requeue tests. No policy should be wired to auto-resume every paused search.
