Completed supervision sessions and owned parent invocations no longer consume a lifetime admission quota. Admission still atomically refuses at128 token-bearing unclosed owners. This is an unresolved-authority bound, not proof of PID liveness. Stop requests and fenced completion remain available at the bound, and a completed owner frees one admission slot without deleting or rewriting retained evidence. Parent/child financial work, frozen policy, source controls and independent observation semantics are unchanged.

Additive partial indexes on token-bearing owner IDs are initialized idempotently for existing schema22 registries. The bounded admission subquery reads at most128 matching index entries; the table/body/receipt format and all retained hashes stay unchanged. No schema row-format migration, evidence pruning or archive deletion is involved.

Both histories expose1..128-row keyset pages ordered by descending SQLite row order. Cursors are retained immutable64-hex record IDs, resolved through their primary key before an indexed row-range query. Unknown/malformed anchors and invalid limits refuse. ID byte lengths are checked in SQL before application text retention, and invalid IDs refuse. New inserts do not shift an older cursor page. Legacy list commands return the latest bounded128 records; new corpus-owned-page/corpus-supervision-page commands traverse the full retained history. Page responses state maximum page size and unclosed-owner admission bound, never a fictitious total-retention maximum.

Authenticated inventories accept strict after/limit queries and return next_cursor. Desktop/mobile first/newer/older navigation commits cursor state only for the owning request, preserves the current page on refresh or stop, and rejects delayed inventory responses. Selected raw exports retain their separate exact record identity and existing stale-detail/security guards. The browser starts no workers.
