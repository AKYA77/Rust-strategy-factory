# Owned bounded visits across frozen inputs

Schema17 adds immutable links from lease-fenced fleet visits to completed owned-parent invocations. `corpus-fleet-supervise DB FLEET POLICY PARENT_LIMITS MAX_VISITS` rotates the original frozen sources in the same deterministic order, using one bounded child round and zero retry waiting per visit. It accepts no arbitrary executable or input retuning. Terminal/operator-held sources start no child; worker-error sources still require the existing frozen retry policy and typed admission. Returned input obstacles remain isolated.

A fleet lease must exceed the parent wall/grace budget plus10000ms margin before claim/spawn. Filesystem stalls can still expire a lease; publication then refuses. Child receipts and parent evidence remain durable independently of fleet publication. The invocation link and fleet counter/cursor changes commit in one transaction. A failed link write rolls back the rotation prefix without deleting an already committed child checkpoint or parent outcome. Migration revokes prior fleet/search coordinator nonces without changing frozen definitions.

Verified fleet status derives per-source owned visit counts, observed/unobserved CPU counts, summed raw native ticks and parent elapsed milliseconds from linked immutable parent summaries. Ordinary visits are not silently counted as measured CPU. These are observations and bounded quanta, not equal CPU allocation or kernel enforcement. Dashboard cards and exact snapshots expose them. A fully idle fleet still pauses; automatic idle recovery must first distinguish scheduler idle from operator pause.

Four new process tests cover complete two-input scalar receipt parity, deterministic links and exact cost/backup consistency, insufficient-lease refusal before claim, injected link-write rollback with retained child outcomes, corrupted-link integrity refusal, missing-input isolation/recovery and operator pause preservation. Actual Chromium/Axum/SQLite fleet tests include an owned child visit, authenticated linked observations/raw export and existing mobile/restart/obstacle controls. Persistent service and target-host acceptance remain unfinished.
