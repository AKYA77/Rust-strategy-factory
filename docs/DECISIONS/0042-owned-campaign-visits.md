# Owned campaign visits and atomic observation links

Schema21 adds bounded immutable campaign-owned visit records and append heads. An unused campaign has a deterministic empty root; the first linked visit creates its head atomically. Chains bind actual immutable parent observation/report digests, the current frozen region and any corresponding advance hash. A visit sequence is the actual campaign claim attempt, so gaps do not invent observations. Linked visits, checks, processes, candidate slots and new simulations are distinct counts. Global links are capped128 and metadata4096 bytes/visit; parent-history quotas still apply.

Explicit campaign supervision launches at most one pinned owned source round per visit, with zero child retry wait. The source lease must exceed parent wall plus grace plus10000ms. Frozen source retry policies cannot retune; pure hints skip backoff, operator/legacy/terminal holds and permanent failures without new child launches or retry-journal polling. Child source leases and admission remain authoritative. Same-executable ownership, sampled resources, output/wall cancellation, cooperative stop and reaping use the existing controller.

A valid parent lease/epoch surrounds the owned call and publication. Only verified source exhaustion advances the region. Parent links, advance records, cursor and append heads commit together. A failed publication retains the completed parent and child evidence without claiming a link. If the source already completed, restart advances from verified existing results without launching another process or attributing the old PID to a new visit. A bounded in-flight child may finish after a parent hold; publication then refuses. Filesystem stalls and hard kernel deadlines remain separate limitations.

Migration revokes old campaign nonces and preserves frozen plans/control intent. A transaction rechecks the live schema so a stale initializer cannot revoke an actor already admitted under the current schema. Managed registry snapshots preserve links and terminal parent observations; restored unfinished campaign leases remain revoked.
