# Frozen OOS cost and stop probes

`fixed-cost-stop-neighborhood-v1` creates deterministic probes without performance input. It changes either both spread floor and adverse slippage by one pip, or the fixed stop by plus/minus `max(1, floor(stop_ticks/10))` ticks. Stop variants outside the grammar domain are omitted. Cost stress outside the supported cost domain rejects the plan. Entry/rule/timeframe/direction/commissions remain fixed. Stops retain the standard 3R planned target policy. This is a small local neighborhood, not complete parameter stability.

Frozen protocol v3 binds the complete derived cases and method version before any OOS work. The trial budget must cover every base candidate and derived case (a conservative count; identical cases can share cached receipts). Exact experiment keys include each effective strategy/cost pair and OOS interval. The same frozen protocol can recover its own probes without falsely treating them as outside exposure. Altering a probe after exposure creates a different protocol and is rejected.

Every probe actually replays each OOS fold from a flat account with causal warmup. It never receives protected-final windows. Stress costs are not estimated by subtracting a fee from old trades: changing executable costs/stops can change sizing, fills, feasibility and the trade path, so each case receives authoritative sequential evaluation. Outcomes need not be monotone in the stress magnitude. All receipts, rejected/failed outcomes and unresolved positions remain explicit. Pooled statistics describe reset-fold accounts, not compounded equity.

The report marks probes `DESCRIPTIVE_ONLY` and retains `INSUFFICIENT_EVIDENCE` overall. There is no fitted acceptance threshold or automatic promotion. Real final execution remains blocked while independent prerequisites are unfinished. No adaptation uses protected-final results. Regime/session analysis, broader rule neighborhoods, dependence-aware inference, approved data coverage and prespecified robustness acceptance gates remain required.

Tests check the exact changes, unchanged base specification, deterministic generation, grammar/cost limits and trial-budget rejection. Actual synthetic protocol tests verify nonzero OOS probe trades, effective concept/cost identities, tick-verification stage, exact fold windows, absence of final-window inputs, immutable reuse and no extra attempts on restart. Old reports omit optional later evidence fields and remain hash-readable without retroactive statistics.
