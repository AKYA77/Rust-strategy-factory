# Shared verified inventory for corpus keys

Batch preflight now mints a private-field immutable inventory with no candle vectors. Scoped workers share its read-only report and retain small no-frame copies. Every cold/cached key consumer checks the exact base/full-specification source binding and fully reopens/decodes/fingerprints currently resolved artifacts before deriving a registry key. This replaces duplicate seven-frame aggregation/hash work. Warm retained contexts keep their own current-byte checks. Candidate costs/budgets/canonical identities, path/operational caps, synthetic literal-USD gates and registry fences are unchanged. Account preparation and saved-prefix semantic recomputation remain mandatory; this is not fast-seek.

The snapshot is no source/scientific approval or current-byte authority. Constructors inspect actual files; private fields, no mutable getter and no deserialization prevent supplied JSON reports from minting a trusted snapshot. Absent candles/signals refuse instead of producing empty context. Two unit tests cover mutation before registration, restored/cached reuse and real/unreviewed/non-USD refusal. One integration test covers inspection/context/path/event-cap/byte parity. A passing compile-fail check proves supplied JSON cannot deserialize the snapshot; hosted CI now repeats it. Existing nonzero full market/stop/limit, mixed-budget, session/restart, forgery and whole-artifact checks remain required.

New inventory_byte_checks counts attempted cold no-frame checks; existing current_byte_checks counts warm retained-context checks. Neither counts all inspections/account reads or proves eligibility. Inventory reports are bounded by256 jobs and contain no candle vectors. The one-frame-slot-per-worker and cross-round worst-case candle reservation rule remain unchanged; other allocations are additional to declared object caps.

Child RSS is not whole-host/service or hard OS measurement. Repeated synthetic cases are not independent scientific trials or actual source coverage. Native/codec/index policy stays unchanged, and real/profile/calendar/conversion, fast-seek, lifetime scaling and scientific/production acceptance remain pending.
