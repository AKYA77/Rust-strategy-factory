# Experimental independently verified native blocks

`RSFBLK01` stores canonical profile/manifest metadata, a bounded authenticated index and SoA quote blocks. Header/index admission caps are2M events,1MiB metadata,4096 blocks and8192 rows per block. Exact file length is checked before allocations. A BLAKE3 root binds header/metadata/index; each index entry binds complete block bytes and first/last event keys. Endianness and full-u64 sequence semantics remain explicit. Atomic no-replace writing retains the original canonical dataset/provenance identity and class.

Sequential readers hold one decoded block and one encoded block plus bounded index/metadata. Every block checks its hash, quote grid/calendar/order and index boundaries before callbacks. A complete successful scan also verifies the canonical JSON event hash and full consumed-file fingerprint. A later failure invalidates the visit; callbacks must not publish early. Header metadata/index state is private and exposed only through immutable accessors.

Range reads require a caller-pinned root from a separately verified/frozen artifact context. They check every touched complete block and return at most65536 selected rows, rejecting overflow/outside ranges and changed lengths. A file's self-reported root is not independent evidence of full source verification. `block-inspect` performs a full scan before reporting the root. Ranges do not grant source approval or qualification. No unsafe memory mapping or production codec selection is introduced.

CLI commands pack/unpack blocks, fully inspect and export pinned row ranges with exact integer strings. The materializing loader remains explicitly capped; streaming corpus integration is next work. Six tests cover all eight symbols/layouts, ties/full-u64 extremes, canonical identity and exact reconstruction, actual CLI exports, malformed/cap/truncation/trailing/no-replace behavior, mutation/root refusal, re-signed invalid quote/content refusal and consumer-error/length-change handling. These are synthetic correctness fixtures, not representative throughput or cold-storage evidence.
