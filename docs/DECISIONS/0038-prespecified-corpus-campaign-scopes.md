# Prespecified corpus campaign scopes

Schema19 stores bounded immutable synthetic corpus campaign definitions independently of execution queues. Freezing a campaign resolves one operator search file, its current source/build identities, fixed seed, contiguous start indices and every declared candidate's exact experiment identity. A digest binds the entire ordered trial scope, including canonical duplicates; the receipt separately counts declared slots and distinct experiment identities. The metadata is not a scientific approval or permission to adapt a protected family.

Campaigns contain1..16 regions and at most4096 total declared slots. Registry metadata is limited to16 campaigns,64KiB each and1MiB total. Definitions cannot be updated or deleted. Identical registration is idempotent; invalid schedules, overflow or grammar failures refuse before registry creation. Backup/integrity preserve and verify the definitions. Current-schema missing tables and corrupt metadata refuse validation rather than being rebuilt as empty history.

The CLI supports freezing, metadata inspection and explicit live input verification. Exact public counters and full-width seeds are decimal strings. Metadata inspection does not imply fresh input eligibility. Live verification regenerates the full schedule and refuses changed source/configuration/build/trial identities. Operational resource limits remain operational inputs and child admission must recheck them. No child search, experiment or process starts during freezing; existing operator-held sources remain held.

Two adversarial unit tests and an actual CLI integration test cover immutable/hash/bounds/duplicate/order/quota corruption, exact complete-family reproduction, u64-max seeds, backup/reopen, no child registration, operator hold preservation, retuning refusal and invalid admission without a registry. Cross-region execution, actor fencing, replenishment, campaign controls and complete scientific family approval remain unfinished. This is an explicit durable prerequisite, not autonomous campaign acceptance.
