# Registry-filesystem admission and publication headroom

Optional `disk_guard: {"minimum_available_bytes": N}` in corpus batch/search operator files checks bytes available to the current user before each bounded round. Positive reserves are required; omit the guard to disable it. Search execution identities exclude this operational threshold, so changing it does not retune a financial experiment. A refused fresh session performs zero rounds and creates no registry. Source/configuration preparation still verifies its inputs before round admission.

Fleet definitions can freeze a global disk reserve. The check runs before coordinator claim or cursor advancement. Per-source search-file reserves remain runtime operational policies: a refused source records a bounded obstacle and rotation continues to other ready inputs. Restore the operational policy and explicitly resume a no-progress-paused fleet. The global fleet definition is immutable, so a different global policy creates a different parent fleet while preserving child search identities. Missing optional global fields retain legacy definition bytes/hashes.

Observations resolve the canonical registry filesystem, or the existing parent of a new registry. Missing parents, in-memory/directory targets, failed queries and inconsistent capacities refuse rather than infer zero or continue unchecked. `fs2`0.4.3 provides the safe Rust API; dependency/lock inputs bind compute identity, and its MIT/Apache notices are retained. Exact decimal-string observations appear in CLI decisions, `disk-status DB`, and authenticated read-only `/api/disk`/desktop/mobile cards. No local paths are returned. Frozen fleet reserve policy is visible as an exact string in its status/card.

These are sampled admission thresholds, not space reservation, inode checks, write-success guarantees, filesystem-stall deadlines or hard OS enforcement. Other filesystems, concurrent writers, user quotas, WAL growth and changing space can still cause later writes to fail. No real disk-full, power-loss or production resource claim follows from forced-threshold tests. Existing transaction/lease fences and recovery remain necessary.
