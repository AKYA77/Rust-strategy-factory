# Retained worker reservations across rounds

Review of the invocation session found a reservation error for heterogeneous candle budgets. The original concurrent cap sums the largest N per-job budgets. That is safe for unique jobs within one round, but a prior-round large context can remain on an idle worker while the same large job prepares a second copy on a different worker. For two jobs budgeted500 and20 candles, a520 aggregate admission does not reserve two500 worker slots. The synthetic regression retains over260 actual candles in its large context, so duplication would exceed520 even in actual object counts.

Before source preflight and dynamic worker assignment, a session now checks workers times the largest candle budget with checked arithmetic. If that worst-case retention reservation exceeds the declared aggregate candle cap (or multiplication overflows), it releases prior slots. Ordinary top-N concurrent admission and within-round reuse remain unchanged; a previously valid heterogeneous batch is not newly refused. Callers with sufficient aggregate capacity, including equal-budget pools and the historical measured fixtures, retain the normal across-round reuse path. This conservative rule does not claim optimal packing or measured RSS enforcement.

A deterministic unit test checks retained buffers under sufficient reservation, tight heterogeneous reservation and arithmetic overflow. A four-artifact mixed M1/H1 two-worker integration test uses500/20 per-job and520 aggregate candle budgets, validates actual duplication risk, checks prior slots are not reused each round, and compares every final receipt field with materialized reference replay. The large M1 case resolves nonzero trades. Fresh source fingerprinting, candidate features/costs/stops, frozen keys, controls, leases and saved-prefix semantic recomputation are unchanged.

Previous synthetic timing receipts remain historical observations for their equal-budget inputs, not evidence of heterogeneous admission safety or universal memory improvement. Quotes, feature masks, retained result reports and other allocations are additional to candle-object reservations. Hard OS/global RSS enforcement, adaptive packing, campaign lifetime scale, fast-seek and scientific/production acceptance remain unfinished.
